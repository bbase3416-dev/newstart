二、功能描述与业务规则

  1. 系统自动处理失败时，按失败原因显示驳回提示，其余失败原因沿用现有提示：
    工单类型未绑定对应账户提交的卡号与已绑定卡号不一致
    修改 IFSCIFSC change failed, you have not tied BankIFSC change failed, Please submit correct bank account number
    修改银行名称Change Bank Name failed, you have not tied BankChange Bank Name failed, Please submit correct bank account number
    删除银行卡自动化Modification failed, you have not tied Bank—
    删除 USDT 自动化Modification failed, you have not tied USDT address—
    删除电子钱包自动化Modification failed, you have not tied UPI—
  2. 规则 1 的提示需支持工单系统现有语言，翻译见「AR多语言翻译文档 › 工单系统多语言」第 4～10 行。
  3. 会员提交以下类型工单时，若本人同一类型已有未结案工单（已驳回、已处理以外的状态，即系统处理中 / 待处理 / 处理中），不允许提交，提示沿用现有重复提交文案（The same type of work order is in progress, please do not submit it repeatedly.）：修改 IFSC、修改银行名称、删除银行卡、删除银行卡自动化、删除 USDT、删除 USDT 自动化、删除电子钱包、删除电子钱包自动化。
  4. 规则 3 按工单类型分别判断，人工版与自动化版互不影响。

三、限制条件

  1. 本次不做：提交前校验会员是否已绑定账户；「全部取款方式」的驳回提示。
